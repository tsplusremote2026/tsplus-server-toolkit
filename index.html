Example

Start with a simple server diagnostic.

The repository includes a basic Python diagnostic that reports core server information. It provides a simple starting point for building more advanced diagnostic utilities.

Explore the repository 
import platform
import socket

def server_info():
    print("=== Server Information ===")
    print(f"Hostname : {socket.gethostname()}")
    print(f"System   : {platform.system()}")
    print(f"Release  : {platform.release()}")
    print(f"Machine  : {platform.machine()}")

if __name__ == "__main__":
    server_info()

Security first

Review scripts before running them.

Server administration tools can make important system changes. Always understand what a script does before using it, especially on production systems.

  • ✓ Review scripts before execution, particularly on production servers.
  • ✓ Never commit passwords, access tokens, license keys, certificates, or other sensitive information.
  • ✓ Keep configuration files free from credentials and private infrastructure information.
  • ✓ Test administrative utilities in an appropriate environment before deploying them broadly.
Get started

Clone the toolkit and start exploring.

The repository is designed to be straightforward to clone, inspect, modify, and use as a foundation for your own server administration and diagnostic workflows.

$ git clone https://github.com/tsplusremote2026/tsplus-server-toolkit.git
$ cd tsplus-server-toolkit
$ python python/diagnostics.py
To compile the C++ diagnostic example:
$ g++ cpp/diagnostics.cpp -o diagnostics
